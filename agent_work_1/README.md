# 作业 / 试卷批改 Agent（优化版）

已增加日常/考试评分场景、答题区域框选、按题合批、性能统计及脱敏训练样本导出。旧配置默认使用 `legacy`。运行 `./start-optimization.ps1`，访问本机 8001 端口；在“模型与策略”选择“日常作业”启用单次评分与合批。

接口、使用方式和离线验证边界见 [第一轮优化验收](docs/第一轮优化验收.md)。本轮未训练新的评分模型；没有教师真值时不宣称准确率提升。

这是一个在本机运行的阅卷工作台：先保存试卷、答案和评分标准，再批量收集学生答卷，最后单独启动批改。支持照片、PDF 和 Word（`.doc`、`.docx`）；可以不选学科。没有教师答案时，可让视觉模型生成**候选**答案与评分标准，核对后固定复用。

## 5 分钟启动

需要 Windows 和 Python 3.11 或更高版本。首次安装：

```powershell
cd D:\ou\agent
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\grading-agent.exe
```

以后直接运行：

```powershell
cd D:\ou\agent
.\.venv\Scripts\grading-agent.exe
```

打开 `http://127.0.0.1:8000`。命令窗口需保持运行；停止时按 `Ctrl+C`。若 PowerShell 找不到 `grading-agent.exe`，可用等价命令：

```powershell
.\.venv\Scripts\python.exe -m grading_agent.cli
```

程序默认只监听本机；**没有登录鉴权，不要直接开放到公网**。

## 试卷、答案、答卷放哪里？

最省事的方式是直接在网页上传，不必手工复制到指定目录：

| 你手里的文件 | 网页位置 | 上传后发生什么 |
| --- | --- | --- |
| 原试卷照片、PDF、Word | **试卷与答案** → 原试卷 | 保存并可预览，用于整理题目 |
| 教师答案、评分标准照片、PDF、Word | **试卷与答案** → 答案/评分资料 | 保存为这套试卷的固定依据 |
| 学生答卷照片、PDF、Word | **答卷收集** | 只保存并去重，**不会立刻批改** |

上传的正式原件、数据库和网页设置保存在 `D:\ou\agent\data\`。这里包含答卷、成绩和可能的 API 密钥，**不要当缓存清理，也不要分享整个文件夹**。`D:\ou\agent\output\` 用于本地导出结果；`src/` 是程序、`tests/` 是测试、`scripts/` 是可选环境脚本。

## 一次完整批改

1. 在 **试卷与答案** 创建试卷，上传原试卷；有教师答案或评分标准就一起上传。没有标准答案时，生成候选答案，逐题核对后确认。固定试卷一般只做一次。
2. 在 **模型与策略** 选择支持图片的服务商/模型，填写对应 API 密钥并保存。可点“测试当前连接”；它会产生少量模型费用，但不会上传试卷。测试成功不等于真实阅卷准确，应先用少量教师已批答卷试评。
3. 在 **答卷收集** 批量上传学生答卷。一个文件代表一名学生；多页请合成一个 PDF。同一套试卷下内容完全相同的文件只留一份。上传阶段不调用模型。
4. 在 **智能批阅** 点击一键批改待批答卷。已有成绩的题在批量重试时通常跳过，缺分题可单独补批；不会为了再次上传而重新生成固定答案。
5. 在 **复核工作台** 按需选择重点复核或全卷复核。模型给出有效分数后即有当前成绩，**复核不是出分前置条件**；人工改分留历史记录，可再次复核。
6. 在 **成绩洞察** 查看最新成绩和分析，按需导出报告；在 **用量记录** 查看模型返回的 Token 用量。

学生可能只提交题号与答案，也可能直接写在原试卷上。上传时可选“仅答案列表”“直接写在试卷上”或“自动判断”。印刷题干和学生手写内容难以区分、漏题或图片不清楚时，需要人工校对；不要把模型候选答案直接当教师标准答案。

## 模型、OCR 与显卡怎么选？

- **最简单**：只用远程视觉模型，不安装 OCR/GPU 环境。在 **模型与策略** 选择平台并填写该平台密钥。切换平台时需提供新密钥；原有自定义 Qwen 地址不会自动改动。
- **可选本地加速**：在 **识别加速** 中启用 PaddleOCR。RTX 4060 只加速运行后端那台电脑的本地 OCR，不能加快云端模型本身。脚本和适用场景见[技术参考](docs/技术参考.md#四个维护脚本)。
- **省 Token**：固定试卷、答案和评分标准只整理一次；客观题优先规则评分；学生答卷按需识别，复核只看异常或抽检项。实际费用仍取决于服务商的图片计费、输出长度和缓存规则。

单文件上限 25 MB，PDF 最多 100 页，普通批量上传每次最多 100 份。旧版 `.doc` 可读取文字，但若关键内容是扫描图、嵌入公式或绘图，请先转为 PDF 或照片。主观题、手写公式及无固定版型答卷应先用真实样本验证，不能保证任意试卷都自动准确批改。

需要排查启动、GPU、模型接口或部署问题时，请看[技术参考](docs/技术参考.md)。
