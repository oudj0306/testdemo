# 第一轮优化：实现与验收

## 使用

保留 SQLite，不训练或下载 MacBERT、Qwen 权重。原项目业务代码不变，优化位于 `agent_work_1`，基线提交为 `1009070`。运行 `./start-optimization.ps1`，访问 http://127.0.0.1:8001 。使用本目录独立的 `data/`；不附带原项目密钥及答卷。

1. 在“模型与策略”选择场景。旧配置默认 `legacy`；`daily` 单次评分、按题合批，结果标记 `AUTO_SINGLE`；`exam` 至少双评、全部提示复核，分歧保留缺分，不取平均。自动建议分不等于教师确认。
2. 在“试卷与答案”上传图片/PDF/Word 原卷，先生成或录入题目，再点击“框选答题区域”，选择资料、页码、题号，拖动框选，预览并保存。Word 使用本机 Word/WPS 或 LibreOffice 转换为保留分页的 PDF 并缓存；不可转换时会说明原因。每套试卷首次配置一次。
3. 启用已有 PaddleOCR 后，可靠区域识别跳过视觉抽取；规则题跳过评分 API。缺页、明显长宽比变化、低置信识别回退视觉模型；失败保留缺分。
4. 批次提供耗时与用量查询。日常模式每次取最多 8 份，先提取，再按题目及完整细则快照合批。两名队列线程各处理一组，单份任务不等待凑批。
5. 在逐题结果“脱敏并批准训练样本”中检查文本并填写批准人，然后分别导出教师确认标签或伪标签。两类均要求批准脱敏文本；教师标签额外要求人工复核记录。复核变化后重新批准；过期批改不导出。

## 行为与限制

- 每份作答有独立标识；检查遗漏、重复、未知标识、分数越界和证据串答。合法结果保留，异常项最多单独补一次请求。独立请求失败最多尝试两次。
- 合批只发送一份题干、参考答案和细则。仅精确文本去重，不使用语义相似答案直接共享分数。
- 日常缓存保留“单次自动评分”状态。缓存包含模型、场景、题目、细则和区域模板，人工复核会使相关缓存失效。
- 评分时标准或作答发生变化，旧结果拒绝保存。延迟返回的自动识别不能覆盖人工作答。
- 区域坐标归一化，适用于同版扫描件及正面拍摄；长宽比偏差超过 10% 跳过区域。无法检测所有同长宽比错页，不提供透视配准。复杂照片可移除模板改用视觉识别。模板修改仅影响后续识别，已有可靠作答保留。
- 记录批次墙钟、排队、识别、评分、数据库事务累计时间。阶段累计值可能因并发或嵌套重叠，不可直接相加。数据库耗时先在内存汇总，避免嵌套事务争锁。
- 请求事件使用独立 ID，评分证据引用请求 ID。合批用量只计一次，缓存命中不产生新请求。解析失败仍记录可获取用量；网络异常或服务商未给用量时不能恢复真实账单。费用为 null，不配置价格不估算费用。
- 本轮不承诺真实评分准确率不下降；日常单次评分及合批均需在代表性答卷上继续评估。

## 接口

| 接口 | 作用 |
|---|---|
| `GET /api/settings`、`PUT /api/settings` | 新增 `grading_profile: legacy / daily / exam` |
| `PUT /api/questions/{id}` | 复用 `rule_config.region` 保存区域，验证页码及坐标；支持 `page_aspect` |
| `GET /api/assessments/{id}/template-page?document_id=…&page=1` | 本地渲染单页 PNG |
| `POST /api/assessments/{id}/template-preview?document_id=…` | 区域对象转裁切 PNG |
| `GET /api/batches/{id}/performance` | 耗时、请求、失败、重试、缓存和 token 明细 |
| `POST /api/grade-items/{id}/training-approval` | `redacted_text`、`approved_by`、`expected_review_id`；无人工复核时 ID 为 null，仅批准伪标签文本 |
| `GET /api/assessments/{id}/training-samples?kind=teacher` | 已批准的教师标签 JSONL；`kind=pseudo` 单独导出伪标签 |

导出包含题目、参考答案、细则及摘要版本、脱敏作答、识别来源、模型、机器分与人工分数变化。排除学生标识、文件路径、图片、密钥、复核人身份及自由文本复核说明。脱敏由批准者检查，系统不声称自动识别所有个人信息。

## 离线对照

固定合成集：50 份、每份 4 题；2 道规则题、1 道重复短答、1 道不同短答。相同输入和确定性模拟模型。原版直接加载 `D:/ou/agent/src`，优化版加载本目录代码，均使用全新数据库。

| 指标 | 原版 legacy | 优化版 daily |
|---|---:|---:|
| 完成答卷 | 50 | 50 |
| 模型请求 | 110 | 8 |
| 每请求最多作答数 | 1 | 8 |
| 模拟输入单位 | 52,470 | 5,388 |
| 模拟输出单位 | 3,520 | 2,311 |
| 本地总耗时，秒 | 2.9987 | 3.1837 |

50 个逐题分数向量一致。模拟用量是固定词法计数器的输出，**不是服务商 tokenizer 或真实账单 token**。不包含网络、真实 OCR 和模型生成，不能外推真实提速、费用或准确率；该次运行优化版本地耗时略高。此对照验证请求消除、结果传递和用量计数。

复现：运行 `scripts/benchmark-round1.py --source D:/ou/agent/src --profile legacy --data-dir output/新基线目录`，再运行 `scripts/benchmark-round1.py --profile daily --data-dir output/新优化目录`；每次生成 `report.json`。目录必须不存在，防止覆盖业务数据；全部模型响应模拟，不联网。

## 验证与后续

最终回归：186 项通过、1 项跳过；JavaScript 语法检查通过。原版 59 个源码、测试和文档文件与冻结清单逐字节一致。另有一条现有依赖的 Starlette/httpx 弃用警告，不影响本轮通过结果。

### Word 与 OCR 启动兼容修复

后续修复回归：194 项通过、1 项跳过。原先模板按钮仅支持图片/PDF且静默禁用，现支持 `.doc/.docx` 原卷转换；无资料或无题目时点击会明确提示。Word 转换禁用宏，以只读方式打开，不修改原件；转换缓存可复用。已用本机 WPS 实际验证两页 DOCX 和 Word 97–2003 DOC 转两页 PDF，以及 .doc 上传、第二页模板加载、裁切接口。

原启动脚本仅寻找 `.venv`，会漏掉原项目已安装 PaddleOCR 的 `.venv-gpu`。现自动检查当前项目和原项目的 `.venv-gpu`、`.venv-ocr`、`.venv`，优先选择装有 OCR 与应用依赖的环境，并复用已有模型缓存。只继承原项目 OCR 的非敏感选项，优化版显式设置优先；不继承密钥或业务数据库。

`./start-optimization.ps1 -PrintRuntime` 可查看环境与独立数据目录，`./start-optimization.ps1 -CheckOcr` 使用合成图片自检。当前机器实测选中 `D:/ou/agent/.venv-gpu/Scripts/python.exe`，识别设备 `gpu:0`，成功识别 `GPU OCR TEST 12345`。两次识别分别约 13.788 秒（首次初始化）和 0.030 秒（预热后）。仍有原环境既有的 cuDNN 编译 8.9.6／运行 8.9.4 警告；自检通过不代表任意手写答卷均准确。

修复后需要重启正在运行的优化服务并刷新网页；直接运行旧环境的 `grading-agent` 命令不会自动切换 Python。可用 `-PythonExe` 显式指定环境。

测试覆盖旧接口、成绩汇总、人工改分与历史记录；新增区域缩放、缺页回退、成功 OCR 和规则评分零请求、8 份上限与尾批、异常结果恢复、跨题及模板缓存失效、评分期间标准变动、人工答案保护及标签隔离。

已使用合成试卷在浏览器验证拖动框选、保存、裁切预览和评分场景入口。真实学校样本的速度、识别准确性及改分率仍待评估；没有使用原学生答卷执行付费 API 请求。

有教师确认数据后，先实验中文 MacBERT 分类头，按题目留出测试集；Qwen3-1.7B 作为生成式对照。本轮没有训练模型，也未启用未经验证的小模型评分。


### 答题区域按钮反馈修复

点击“框选答题区域”始终打开窗口：缺少试卷、原卷或题目时，在窗口内说明下一步，并可返回对应的准备入口。已有 Word 原卷但没有题目时，可以先预览，生成或录入题目后再保存区域；打开窗口自动加载对应页面。首页禁用 HTML 缓存，并更新脚本版本，避免旧界面残留。

框选对象是原试卷上的学生作答位置，供学生直接在同版试卷上填写后的答卷复用。另纸作答或仅答案列表不能直接套用原卷位置。本次用独立的合成 Word 试卷验证按钮打开、自动预览、鼠标拖选及保存，不使用实际学生数据。


### 框选输入与适用范围补充

允许尚无题目时先框选和预览，保存仍需关联题号。拖动在松开时更新最终位置，增加两点框选和逐步状态提示；缩放坐标、反向框选、无题目草稿状态有行为测试覆盖。

按题号保存，不按题型共用位置，也不必所有题都配置。选择题在作答选项可靠提取后使用 choice_set 规则评分；本版区域功能是裁切加 OCR，不是填涂 OMR，不能把印刷选项或涂黑自动等同于已识别的学生选择。未配区域仍走原识别路径。


### 自动选择题与框选后保存

选择题无需手工区域：上传后按题号由已配置的视觉 API 读取选项，再由 choice_set 规则判分；不提供本地零 token 填涂 OMR 的声明。普通 OCR 不能区分印刷选项和涂黑标记，因此不再用其区域结果作为可靠选择题作答；旧区域仍留存，但不用于选择题识别，人工修正保留。选择题混合答卷也不走整页 OCR 文本替代图像路径。

非选择题框选完成后自动弹出浮动操作卡片，支持直接选择保存题号、裁切预览、取消和保存；选择题不出现在区域保存列表。保存目标已有区域时提示覆盖。工作台增加识别与框选的说明，统一工具栏、页面底板及操作卡片样式。

验证：合成 Word 原卷中从第 1 题视图拖动框选，在浮动卡片切换保存到第 2 题，预览并保存成功。自动选择题上传、原有选择题区域兼容、规则判分有模拟视觉 API 的端到端测试，未调用付费模型，也未据此宣称真实填涂识别准确率。


### 自动模板与本地学生识别

新增一次性模型模板解析，之后本地对齐、空白模板差分填涂检测及 PP-OCRv5 区域识别。模板携带大题、小题元信息，固定题号不重新编号；手工区域作为文字题位置纠错入口。本地模式失败不回退视觉 API，缺失不计零分，合法部分可继续出分。详情与验证边界见《本地识别模板.md》。本轮 224 项测试通过、1 项跳过；合成答卷真实 GPU OCR 与本地 OMR 识别 B / 42 并由规则判分，远程请求为 0，模板模型坐标采用模拟输入。
