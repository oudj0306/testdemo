# 混合识别与人工复核

本轮不下载或训练新模型。保留本地识别，改为本地优先、疑难项调用已配置 API。原项目及其数据库保持不变。

## 识别与判分

1. 空白答题卡模板定位一次；学生答卷使用对应位置本地裁切与识别。填涂选择题仍走本地 OMR。
2. 文字两次完整转写一致、无不确定项且通过结构校验，直接采用。来源为自动识别，不等于教师确认；流程图、涂改等未通过校验项转入疑难分支。
3. 开启“疑难项 API 回退”且配置了视觉 API 后，只补识尚不可靠的题目，每轮先请求一次；局部裁切返回空文字且未确认空白时，自动使用对应原始完整页再请求一次。有效非空转写不做重复请求。裁切完整时仅发送该题全部区域，裁切不可复用时回退原件；已知缺页直接提示补页。识别请求不附标准答案或评分细则。
4. API 未返回文字且没有明确空白时保留缺分及候选，不能当空白记零。API 返回通过结构校验的非空文字直接用于判分；低自报置信度保留复核提示，不再要求人工点击采用。成功的本地结果、人工校正不被补识覆盖。
5. 明确确认空白直接规则记 0，包括主观题。自动空白采用本地两次明确空白或API 明确空白；人工也可点击按钮确认。OCR 空输出、缺页、异常本身均不构成空白。
6. 可靠作答优先规则判分；明确的固定答案对错直接出分。规则解析失败、表达形式待核实或允许语义判断等不确定项交给文本评分 API；主观题按现有细则评分。策略仍遵守 legacy/daily/exam，考试复核要求不被移除。

两次同模型转写具有相关性，一致不保证正确。规则回退中的文字相近判断只决定是否请模型判断，不直接共享答案分数。

## 操作

进入“复核工作台”默认重点复核，先展示缺分和建议关注题。作答校对折叠放在当前题目之后，保留全部题号；可独立设置每页5/10/20/50题、上一页及下一页。点击“校对本题”后进入全卷模式并跳到该题。

- 输入正确转写，点击“确认作答并判分”：保存为人工作答来源，仅重新判本题，其他题的人工成绩保留。
- 确实未作答，点击“确认未作答并记0分”：无需填写文字。文字与空白确认不能同时提交。
- 本地转写分歧、检测到涂改（包括两次文本相同）、困难文字或识别失败，自动补调已配置的视觉 API；主操作区不需要手工触发 API。来源显示“API补识 · 已采用 / 仍不确定 / 调用失败”，识别记录保留触发原因和候选。旧只读预览接口仍兼容，但不再占用主操作区。
- 需要教师确认分数时，使用“确认本题评分”。作答确认和教师分数确认分别记录，不把普通自动出分当教师标签。

运行设置可关闭“疑难项 API 回退”，恢复仅本地识别及原评分路由。已可靠识别答案不会仅因设置变化重新收费识别。未识别题均保留编辑入口，不要求先完成整卷批改。

## 启动

在项目目录执行：

```powershell
.\start-optimization.ps1 -Port 8001
```

代码更新后先在原服务终端按 Ctrl+C，再启动；端口已运行时启动器只提示已有服务，不自动替换。启用 API 补识且配置可用时，本地视觉服务启动失败也允许进入工作台，并在识别时走补识路径。API 调用失败仍保留人工处理入口。

## 验证边界

隔离数据已通过实际浏览器操作验证：无识别结果的题目可见、手输答案立即判分、手动空白记零、其他题的教师成绩保留。真实配置的视觉 API 已进行一次只读裁切预览，连接及输出校验成功，但该样本返回低置信度空文本，系统正确保留不确定。该测试不证明手写识别准确率提升，也不承诺 API 能读清每份答卷。原始图片、学生身份、密钥和诊断不入 Git。

最终隔离工程回归：334 passed、1 skipped（46.35 秒）。覆盖原有路径、两次一致采纳、API 部分失败保留、缺页保护、空白判零、逐题人工判分、预览不改成绩、异常响应用量保留及前端候选安全显示。JavaScript 和 PowerShell 启动脚本语法检查通过。工程测试不等同于识别准确率评测。

复核界面更新验收：337项通过、1项跳过。使用23题合成答卷浏览器点验，从智能批阅进入即显示重点复核，作答校对可翻页及调整每页数量。耗时与用量改为批次卡片底部折叠栏，展开显示六项统计。本轮未调用付费API或新增模型，特殊情况的自动回退使用模拟接口集成验证。旧答卷已有可靠结果不会因更新自动重识别，需重试缺分题才会补识旧缺失结果。

## 旧答卷重试入口修复

发现已进入 `review_required` 的旧答卷此前在单卷和批次重试时都跳过识别阶段，导致旧 `local_only` 缺失结果一直保留。现在识别是否需要补做取决于实际作答可靠性，不再只看答卷状态。已有本地诊断的旧答卷直接复用保存的裁切或原页补调 API，不重新启动本地视觉推理；API 与本地候选不同直接采用 API 结果。自动识别不覆盖人工作答，逐题重判保留其他题的成绩。

真实现有答卷补识验证：24题中的20题可靠结果保持，4道旧缺失题自动发出4次视觉API请求，均返回非空文字并进入判分；最终未识别题0、缺分题0，6条原有人工分数及记录标识保持。此结果验证真实调用和处理链路，不表示逐字转写准确率达到100%。诊断、转写及原图保存在忽略的本地output目录，不提交仓库。

完整隔离回归：340 passed、1 skipped（45.21秒）。新增覆盖旧复核状态单卷/批次重试、API与本地候选冲突、裁切空响应自动转整页、两次请求用量只计实际总量、API明确空白采用且保留低置信度提示。
