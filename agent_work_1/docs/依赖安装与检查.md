# 依赖安装与检查

## 哪些依赖需要安装

| 环境 | 安装组 | 用途 |
| --- | --- | --- |
| 仅 API / 基础工作台 | 项目基础依赖 | Web、文档读取、数据校验、规则判分 |
| 本地版面识别 | `local_recognition` | NumPy、OpenCV，用于对齐、裁剪、填涂定位 |
| OCR 前端 | `ocr_engine` | PaddleOCR 及与其一致的 OpenCV 版本，不包含 Paddle 运行时 |
| CPU OCR | `ocr` | OCR 前端与 CPU Paddle 运行时 |
| GPU OCR | 官方 GPU 安装脚本 + `ocr_engine` | 按 CUDA 版本选择官方 GPU Paddle wheel |
| 开发与验证 | `dev` | pytest、HTTP 测试客户端和 Ruff |

基础依赖显式声明直接使用的 Starlette，及依赖检查使用的 packaging。`local_recognition` 与 PaddleOCR 统一使用 `opencv-contrib-python`，避免另装 headless 版本覆盖同一个 `cv2` 模块。OCR 前端锁定在已验证的 3.7 系列，其要求的 OpenCV 版本是 `4.10.0.84`；NumPy 范围同时满足当前 PaddleX 的声明。

CPU 与 GPU Paddle 分发包共享 `paddle` 文件，不能在同一个虚拟环境里同时安装。GPU 环境不要执行 `pip install ".[ocr]"`。

本地视觉转写通过 Ollama 服务运行。当前代码不直接使用 PyTorch、Transformers、Accelerate 或 qwen-vl-utils，因此不把它们当“缺失依赖”安装。模型权重、Ollama、Word/LibreOffice 是模型文件或外部程序，与 Python 包分开管理。

## 安装

在优化版根目录，使用目标虚拟环境的 Python。基础开发环境：

```powershell
python -m pip install -e ".[dev]"
```

CPU OCR：

```powershell
.\scripts\setup-ocr.ps1
```

GPU OCR：

```powershell
.\scripts\setup-gpu.ps1 -Cuda cu118
```

GPU 脚本按现有流程使用官方 Paddle CUDA 索引；支持 `cu118`、`cu126`。驱动及 GPU 能否实际执行由该脚本的 GPU 运算检查确认，普通依赖元数据检查不能替代它。

这轮未重装现有共享 GPU 环境：只读检查表明所需依赖和版本均已满足。安装声明已经补正，今后新装使用上述分组即可。

## 检查

通用检查（不连接 API、不初始化模型、不下载权重）：

```powershell
python .\scripts\check-dependencies.py --profile local
```

当前 GPU 环境的完整开发检查：

```powershell
& D:\ou\agent\.venv-gpu\Scripts\python.exe .\scripts\check-dependencies.py --profile gpu --include-dev
& D:\ou\agent\.venv-gpu\Scripts\python.exe -m pip check
```

`--profile` 可选 `basic`、`local`、`cpu`、`gpu`；`local` 优先使用已安装的 GPU Paddle，不会要求在它旁边再安装 CPU 版本。加 `--json` 输出结构化结果。检查退出码 0 表示依赖元数据满足要求，1 表示缺包、版本不符或共享模块冲突。

若提示冲突，先确认在正确的虚拟环境处理，不要在运行服务的环境里随意卸载。这个检查器只报告，不自行修改环境。

OCR 实际执行检查仍使用原来的入口，已修复其模块迁移后的导入路径：

```powershell
.\start-optimization.ps1 -CheckOcr
```

它会运行本地 OCR，与上面的纯依赖检查不同。

## 测试跳过与缺依赖的区别

上轮两项跳过分别是未提供旧 DOC 测试样本，以及测试会话的 PowerShell 执行策略不允许运行脚本。安装 Python 包不能解决这两项，也不会为此修改系统执行策略。

本轮增加了启动脚本内嵌 Python 导入检查和依赖声明覆盖检查，防止只移动 Python 文件却漏改 PowerShell 中的路径，或增加第三方 import 后漏写安装依赖。
