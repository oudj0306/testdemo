# 代码结构与维护规范

本次整理针对优化版 `agent_work_1`，原版及生产数据不迁移。启动指令与 HTTP 接口保持兼容，Python 内部导入路径已调整；外部自写脚本需要按下表更新导入。前端页面和交互本轮未改动。

## 边界与命名

- 识别模块负责转写，评分模块负责分数；共用识别质量判断不反向依赖评分编排。低层模型通信不依赖 Web 应用。
- `GradeDecision.score=None` 表示缺分，不能变成零。`needs_review=True` 是复核提示，不得抹去合法数值。
- 已采纳的人工、API、本地双转写结果与普通 OCR 的置信度判断分开。无效置信度按未知处理；API 转写不因缺少自报置信度退回人工必填。
- 外部 JSON、历史数据、模型响应都在边界验证。异常的批量答案标识在发请求前拒绝；非法数字、无限容差不能生成规则分。
- 接口字段与数据库列保持兼容；内部名称使用用途明确的英语词组。索引可用短变量，业务对象避免单字母缩写。
- 注释说明设计原因、输入前提、回退条件及事务/并发限制，不逐行复述代码。关键共用函数注明输入输出与副作用。
- 本地视觉、OCR 等可选依赖继续按需加载，导入应用不能初始化模型或下载权重。
- 评分单次重试作为 `OpenAIGrader.grade_daily` 的明确服务入口；批量模块不调用另一个模块的私有方法。

## 已减少的重复工作

| 路径 | 整理后的处理 | 复杂度说明 |
| --- | --- | --- |
| 指定题目筛选 | 指定 ID 一次转集合，再筛题 | 原列表成员检查最坏 O(NK)，现在平均 O(N+K)，额外 O(K) 空间 |
| 同一框内填空区域列边界 | 预先计算左右两列范围 | 列范围计算与复用由 O(R²) 降为 O(R)，边界表最多两项；排序等其他步骤仍保留 |
| 符号等价判分 | 一次化简并复用差值 | 减少相同的符号运算；不承诺任意表达式的化简都是线性复杂度 |
| 每空可接受答案 | 顺序惰性匹配，匹配成功即停止 | 最坏扫描次数不变，避免为一次查询构造整个集合 |
| 文字规则转模型判断 | 提前判断作答是否含字母/汉字 | 避免对每个参考答案重复扫描相同作答 |

不存在对所有输入都同时达到最低时间和最低空间的通用写法。本轮优先减少重复计算并保持规则含义，不移除有效性校验来换速度，也不据此承诺实际 OCR/API 耗时降幅。

## 日常检查

安装开发检查工具：

```powershell
python -m pip install -e ".[dev]"
```

在优化版根目录运行：

```powershell
python -m ruff check src tests scripts
python -m ruff format --check src tests scripts
python -m pytest -q --basetemp=output/pytest-check-新编号
```

`--basetemp` 每次使用新的目录名，避免清理上次保留的调试文件。测试使用隔离数据库及模拟 API；不能据此宣称实际手写识别率或评分准确率提高。生产服务需由用户重新启动后加载新结构。

Word 转换辅助脚本随 `services/documents/` 打包；移动模块时同时检查包资源、脚本入口、动态导入及测试替换目标，不能只修改静态 import。
