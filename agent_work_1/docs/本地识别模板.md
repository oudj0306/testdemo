# 一次生成位置模板，本地读取学生答卷

## 使用步骤

1. 用优化版 `start-optimization.ps1` 启动服务（默认 8001，优先现有 GPU Python）。重启后按 Ctrl+F5 刷新界面。
2. 上传原卷、标准答案。可以先生成或录入题目，也可以直接进入下一步。题号保持原卷编号；每大题重新编号时采用“一-1”“二-1”等完整编号，不因排除选择题而重新编号。
3. 在“自动位置模板”选择来源：没有题目时点击“识别题目并生成模板”，依次识别题目与候选答案、生成位置模板，首次需要两步模型请求；已有题目时点击“生成并启用本地模板”。候选答案仍需核对。若学生使用独立答题卡，把空白答题卡按“原试卷”类型上传，并选择它作为模板来源。重复点击复用有效模板；重新生成需勾选。
4. 点击“预览自动区域”，按页核对蓝色文字区和绿色填涂区。题目卡片和区域列表显示模型解析的大题、小题。非选择题位置有误时，可在框选工作台纠正；框选后选择保存题号。当前手工纠错会以单个框替换该题已有区域（包括多个跨页区域）；跨页题优先通过重新生成修正。首次建议核对一次，不需要逐题手工创建区域。
5. 上传同版学生答卷，在智能批阅页开始批改。本地执行版面特征匹配和透视对齐、气泡填涂检测、PP-OCRv5 区域识别。有明确判定规则的题由规则评分，需要理解语义或步骤的题只把识别文本传给原评分模型。
6. 识别不确定、模板漏题、错页或缺页保留缺分和原因。答卷复核页显示本地识别详情，可人工校正作答后重新批改。已有可靠作答、人工改分和历史记录继续保留。

## 模式与边界

- 启用自动模板后，学生答卷识别为 local_only，即使识别失败也不自动回退收费视觉 API。模板过期时同样保留缺失；重新生成或人工修正后处理。
- “停用并恢复原识别路径”是显式回退开关；停用后按原设置决定是否调用视觉 API。未配置自动模板的历史试卷保留原流程。
- 同一试卷可有多个来源文件，当前一次选择一份文件作为完整模板；多页合并为一个 PDF。模板支持可渲染的图片、PDF、Word，1～12 页。学生答卷同样按一名学生一个文件收集，页序需要与模板一致。
- Word 需本机 WPS/Word/LibreOffice 成功转换。答题卡与原卷版式不同时不能混用位置；另一种版式需要独立模板/试卷。
- 本轮不是支持任意另纸作答、任意透视或任意乱序页面的通用识别器。对齐特征不足或几何异常时明确失败。简单卡片若缺乏足够分布的印刷特征，也可能无法可靠对齐。
- 填涂采用空白模板差分、印刷轮廓检查与填充比例规则；浅涂、擦改及单选多涂保留不确定。阈值是工程启发式，尚未用真实答题卡标定，不代表已验证的识别准确率。
- 文字区域 OCR 不把“没有识别到文字”自动判断为空白；复杂手写公式、图形仍可能失败或误识，需实测及复核。此版本未新增公式识别权重，也未训练评分模型。
- 本地路径不产生视觉 API token；主观题的文本评分仍产生模型 token。本地推理有 CPU/GPU 成本。模型定位置信度也不是经过校准的准确率。

## 接口

- GET /api/assessments/{id}/layout-template：状态、结构、大题/小题、依赖检查及模板版本。
- POST 同地址：JSON {document_id, force:false}，一次生成并启用；有效模板缓存命中时不请求模型。
- PUT 同地址：JSON {enabled:true/false}，显式切换本地模式与原路径。
- GET /api/assessments/{id}/layout-template/page?page=1：自动区域标注预览。
- 手工文字区域纠错复用题目 PUT 接口及 rule_config.region，同时更新自动模板，不影响已保存作答。

SQLite 新表 assessment_layouts 保存模板及来源指纹，原卷页面保存在独立优化版 data/layout-pages。题目、题型或来源变化会使模板过期。normalization_report.local_recognition 记录模板标识、对齐结果、填涂测量、缺失题和原因，不保存密钥。

## 本地依赖与验证

现有 .venv-gpu 已包含 OpenCV、NumPy、PP-OCRv5，本轮直接复用。新环境可安装项目的 local_recognition 和 ocr 可选依赖，并按本机 GPU 配置 Paddle；不要用不含 Paddle/OpenCV 的 Python 启动本地模式。

- 全量回归：224 passed，1 skipped。新增覆盖真实 OpenCV 平移对齐、错版拒绝、正常填涂、浅涂、单选多涂、多选、缺页、错误模板、缓存、过期、人工保护、部分识别失败出分、日常批次、主观题仅文本评分、依赖缺失及失败不回退 API。
- `scripts/verify-local-layout.py`：在隔离的 output/local-layout-real-check 生成合成答卷。模板模型被模拟，学生识别及规则判分使用真实本地算法，远程调用被禁止。已用现有 GPU PP-OCRv5 实测识别 B 和 42，各得 5 分；重复生成复用模板。
- 该次合成验证识别及评分耗时 6.187 秒，包含冷启动；不是整班性能承诺，也不是相对原版的真实加速比例。模板来源坐标为预设测试数据，不能作为模板生成模型真实准确率证据。
- 本轮未用用户真实试卷调用付费模型；真实模板定位与代表性手写样本效果仍待验证。未下载或训练 MacBERT、Qwen 等权重。


## 2026-10-22 再检查与修复

- 自动区域移除改为显式删除模板映射，成功后即时刷新界面，避免旧框继续显示或识别。
- 手工纠错携带来源资料标识；与自动模板资料不同则拒绝并回滚，默认选中模板对应资料。
- 页面与裁切请求检查当前请求版本；旧页面、旧错误、窗口关闭后的响应不能覆盖新选择。
- 模板生成每次使用独立且不覆盖的页面快照。生成失败保留旧页面；模型等待期间发生的教师纠错不会被新结果覆盖。
- 本地模板状态及坐标使用同一快照，等待锁后刷新题目；历史模板也会重新校验已知选项和编号连续性，失效后保留本地模式与缺分。
- 单选题文字 OCR 读出多个选项，以及非有限或超出 0～1 的置信度，均保留缺分；本地依赖无法载入时显示诊断。
- 灰度转换与整页亮度统计按页复用，不再为每一道题的每个选项重复计算。

验证：235 项通过，1 项跳过；浏览器验证自动区域移除后旧框及映射均消失；真实 PP-OCRv5 GPU 与本地填涂再次识别合成 B、42 并各得 5 分，远程请求 0。此次冷启动验证耗时 11.766 秒，不能用于推断稳定吞吐或节省比例。现有 Paddle/cuDNN 兼容提示仍存在，未改动系统驱动或重装环境，实际推理通过。

仍需真实试卷、拍照答卷与手写样本验证：大模型生成坐标的真实定位效果、手写/公式 OCR 准确率、不同拍摄条件下的阈值与对齐稳定性。本轮未调用真实付费模板模型，不宣称已验证这些指标。


### 2026-10-22 模板入口与框选起点修复

发现实际试卷处于“已有资料、没有题目”状态，旧界面禁用了模板入口，也没有可供区域保存的题号。现在入口可直接识别题目后生成模板，显示两个阶段、模型用量提示及失败原因；已有题目不重复生成。候选题目全量校验后原子写入，重复编号或非法结果不会留下半套题目，也不覆盖已有题目。

无题目时仍可框选、预览；点击“识别题目后选择题号”后保留选区，完成后明确选择题号并再次保存。弹窗默认整页适应，可切换按宽度查看；已存区域自动切换对应页，识别后题号选择器立即恢复可用。

验证：244 项通过、1 项跳过。用隔离数据及两页合成 .doc 在实际浏览器验证：零题目入口、生成并启用模板、拖动、裁切预览、识别后保留草稿、指定二-1 保存成功。Word 转换、页面显示和保存使用真实本地代码；题目与模板模型响应使用模拟数据，未调用付费 API，不能据此宣称真实模型定位或答案准确率。
