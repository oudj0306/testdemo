# 优化工作区

本目录保存 2026-10-21 的作业批改 Agent 基线。原有评分逻辑保持不变，后续优化在此目录开展。

## 启动

从本目录执行 `./start-optimization.ps1`，默认地址为 http://127.0.0.1:8001 。该脚本强制从本目录的 `src/` 加载代码，并使用本目录的 `data/`，不会连接原版数据库。

本机可借用上级目录已有的 `.venv`。在其他机器使用时，先在本目录创建 `.venv`，再执行 `python -m pip install -e ".[dev]"` 安装依赖。API 密钥在启动后单独配置，源码不附带密钥、学生答卷或数据库。

## 优化顺序

1. 记录识别、评分、排队耗时，区分输入、输出、缓存及重试用量。
2. 用固定试卷验证答题区域定位、局部识别与规则评分。
3. 比较按题小批处理、共享前缀与疑难追加评分。
4. 积累教师确认数据，按题目留出测试集，再评估短答案判别模型与蒸馏。

日常作业允许自动出分并标记疑难结果，重要考试使用更严格复核策略；两者的给分细则必须保持各自一致。识别失败保留缺分，不自动记零分。

## 版本保留

Git 基线标签用于恢复代码。本机另存含业务数据的私有压缩快照，快照位于仓库外，不上传 GitHub。基线说明表示保存当时实现，不代表评分质量已经通过独立教师评测。
