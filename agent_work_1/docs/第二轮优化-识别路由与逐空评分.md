# 第二轮优化：识别路由、逐空规则和复核操作

日期：2026-10-28。所有代码位于 `agent_work_1`；原项目不改动。

## 识别与评分的实际路径

1. 答题卡先本地对齐，填涂题继续使用 OMR。缺页或对齐失败不能判为空白。
2. 数值题区域先尝试 OCR。仅高置信度、符合完整数值格式的结果可跳过本地视觉模型；不拿标准答案纠正识别文字。其他短文本保持原有本地转写与不可靠时 API 补识。
3. 编程、流程图直接使用视觉 API；每题也可选择“本题直接使用视觉 API”。这需要已启用 API 补处理、视觉识别并配置密钥。否则保留本地路径。
4. 困难题仍优先上传完整的本题裁切区域。只有空且未确认空白的 API 返回才增加一次对应整页上下文请求。有效 API 内容优先采用，保留来源标记。
5. 明确空白继续规则记零；识别失败不能视为空白。固定答案按已配置规则计分，其余交评分模型。

直接 API 路由绕过本地推理，因此可能增加相对原来“本地成功”路径的 API 费用，但减少已知困难题的本地等待。没有真实同卷对照前，不声明速度、费用或准确率提升比例。

## 如何配置固定填空

在“试卷与答案 → 参考答案与评分标准”的对应题目中，展开“固定答案规则与识别方式”。

- 勾选“启用逐空答案规则”；每空填写可接受答案和分值。
- 同一空的多个答案以 `|` 分隔；多空按原题顺序添加，每空分值之和须等于本题满分。
- 例如两空各 2 分：第一空 `控制器`；第二空 `存储器 | 内存储器`。
- 未列出的文字默认交模型判断，避免漏掉合理同义答案。只有答案完全确定时才勾选“未列出的答案直接判错”。
- 多空作答必须能按换行、逗号、顿号或分号分成相同数量的空；分隔或顺序不明确时回退模型，不猜测对齐。
- `[未作答]` 表示已明确识别的该空未答，可以部分计分。缺少分隔、少空或多空不会静默当错。
- 未确认的答案标准和人工判分模式不启用自动逐空规则。规则保存不改旧成绩、不更换原参考答案、不重新生成位置模板。

规则通过原有题目更新接口保存于 `rule_config.fixed_answers`：

```json
{"blanks":[{"accepted":["控制器"],"score":2},{"accepted":["存储器","内存储器"],"score":2}],"strict_mismatch":false}
```

这是一份按题维护的评分依据，不是语义相似答案共享分数。需要教师准备或核对一次；本轮不从历史模型输出自动批准同义答案。

## 减少重复与复核操作

- 本机优化版设置已切换为 `daily`：普通评分单次，同题批次至多 8 份；考试仍可在“模型与策略”切换 `exam`。
- 保留旧安装缺省 `legacy` 的兼容行为。配置只影响后续评分，已有机器分、人工分和历史记录不改动。
- 教师仅确认原机器分数，不清空该题评分缓存；出现真正改分或不可核验的旧记录时仍保守失效。题目、细则、模型、策略版本变化仍会改变缓存键。
- 缩短模型实际需要返回的原因和证据，并更新提示词/批量算法缓存版本。不是依靠降低输出上限来声称节省实际 token。
- 本题分数和复核操作移到右侧作答之前，桌面滚动时保留操作区；“保存并下一题”保存成功才切题，保存失败保留输入。
- 作答完全未改且已有数值成绩时，不重复提交判分。需要修改识别文字时仍可编辑保存；机器出分不等同于教师确认。
- 页面与后台新增版本提示。旧服务未重启时，不允许新规则看似保存却未被执行。

## 知识库取舍

当前已有批准样本及资料搜索的基础接口，但没有把任意检索结果自动作为评分真值。当前建议先使用题目专属标准、同义答案和采分点；这比给所有答卷追加通用资料更容易核验，也避免额外检索上下文。

后续只有当评分确实依赖教材版本、课程术语或校本标准，且出现稳定的缺依据错误时，再增加带出处、版本和教师审批的资料检索。OCR 错字靠识别与图像证据处理，不靠检索把学生答案补成标准答案。本轮不新增向量数据库、不训练或下载模型。
