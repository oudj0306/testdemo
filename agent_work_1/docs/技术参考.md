# 技术参考

这份文档供维护、排障和部署时查阅。日常上传试卷与批阅，请先看项目根目录的 [README](../README.md)。`docs/screenshots/` 仅存放界面截图，不是操作步骤。

## 代码与数据在哪里

| 路径 | 用途 |
| --- | --- |
| `src/grading_agent/app.py` | FastAPI 接口、上传和设置入口 |
| `src/grading_agent/cli.py` | `grading-agent` 启动命令；默认只监听 `127.0.0.1:8000` |
| `src/grading_agent/config.py` | 环境变量和网页设置的读取、保存 |
| `src/grading_agent/storage/` | SQLite 表与业务数据访问 |
| `src/grading_agent/web/` | 工作台页面路由与优化接口 |
| `src/grading_agent/infrastructure/` | 环境依赖检查、统计、锁与本机路径 |
| `src/grading_agent/services/model_io/catalog.py` | 可选视觉模型及官方文档链接 |
| `src/grading_agent/services/model_io/model_transport.py` | Responses、Chat Completions、Claude Messages 请求转换 |
| `services/documents/ingestion.py`、`services/model_io/vision_input.py`（位于 `src/grading_agent/`） | 文件归一化、PDF 按需转图片 |
| `src/grading_agent/services/recognition/answer_extractor.py` | 从学生答卷提取作答 |
| `src/grading_agent/services/documents/assessment_compiler.py` | 从试卷/答案资料生成候选答案与评分标准 |
| `src/grading_agent/services/scoring/` | `submission_grader.py` 批改编排、`llm_grader.py` 模型评分、`rule_grader.py` 确定性评分 |
| `src/grading_agent/static/` | 网页界面 |
| `tests/` | 自动化测试，不存放正式答卷 |
| `data/` | 本机业务数据：数据库、设置、原件和处理中间文件；**不要当作可随意清理的缓存** |
| `output/` | 本地导出产物，删除前先确认是否还要保留 |
| `.venv/`、`.venv-gpu/`、`.venv-ocr/` | 互相独立的 Python 环境，不是试卷存储位置 |
| `tests/artifacts/runs/` | 历史测试运行记录，保留原文件名以便追溯 |
| `tests/artifacts/temp/` | 旧临时测试文件和验证运行目录 |
| `tests/artifacts/cache/` | 新 pytest 缓存；不属于正式业务数据 |
| `.pytest_cache/`、`src/*.egg-info/` | 旧测试缓存或安装元数据；不是用户文档 |

`data/settings.json` 保存网页模型设置和密钥，`data/grading.db` 保存业务记录。不要提交、分享或直接编辑前者，也不要手工删除 `data/` 以“清缓存”。设置优先于相应环境变量；`.env.example` 只是配置示例，程序不会自动加载 `.env`。

## 四个维护脚本

| 脚本 | 何时使用 |
| --- | --- |
| `scripts/setup-ocr.ps1` | 可选：建立独立的本地 OCR 环境 `.venv-ocr` |
| `scripts/setup-gpu.ps1` | 可选：安装 GPU OCR 环境 `.venv-gpu`，不覆盖主环境 |
| `scripts/start-gpu.ps1` | 使用 GPU 环境启动；加 `-CheckOnly` 仅检查 |
| `scripts/check-gpu.py` | 测试本机 GPU 张量计算与合成图片 OCR，不调用云模型 |

GPU 只能加速本地 OCR，不能让远程大模型变快。服务器部署后，“本地”指服务器而不是浏览器电脑。只用远程视觉模型时不需要安装 PaddleOCR，也不需要 GPU 自检。

在 Windows PowerShell 中，按需要选择**一种**可选环境，不要把 OCR 包混装进主 `.venv`：

```powershell
cd D:\ou\agent
# 可选：CPU/通用 OCR 环境
powershell -ExecutionPolicy Bypass -File .\scripts\setup-ocr.ps1
.\.venv-ocr\Scripts\python.exe -m grading_agent.cli
```

```powershell
cd D:\ou\agent
# 可选：NVIDIA GPU OCR 环境
powershell -ExecutionPolicy Bypass -File .\scripts\setup-gpu.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start-gpu.ps1
# 仅检查环境，不启动服务：
powershell -ExecutionPolicy Bypass -File .\scripts\start-gpu.ps1 -CheckOnly
```

`setup-ocr.ps1` 固定要求 64 位 Python 3.12；`setup-gpu.ps1` 默认选 3.12，也可用 `-PythonExe` 指定 3.11–3.13 的 64 位解释器。主环境的 Python 版本可与 OCR 环境不同。安装后还要在网页 **识别加速** 中选择 PaddleOCR 和设备；只安装包不会自动改变识别方式。OCR 首次初始化可能下载公开模型权重。合成图片自检只说明环境能运行，不代表真实手写答卷的识别准确率。

## 工作流与数据边界

1. 上传原试卷、教师答案或评分标准。没有答案时可生成候选答案，但应核对后确认并固定复用。
2. 上传学生答卷时只存原件并按相同试卷下的文件内容去重，不立刻识别、批改或消耗模型 Token。每个文件对应一名学生；多页请合成一个 PDF。
3. “智能批阅”单独启动队列。规则能确定的题优先本地评分；其余按需识别与模型评分。已出分的题在批量重试时跳过；缺分题可重试。
4. 模型给出有效分数后形成当前成绩，不必先人工复核。重点复核和全卷复核均可选；人工修订追加历史记录，统计读取最新成绩。

单文件上限 25 MB；PDF 最多 100 页；普通批量上传单次 1–100 份。照片、PDF、`.doc`、`.docx` 可用于相应上传入口。旧版 `.doc` 读取正文、表格和部分附属文字，但不保证保留排版、扫描图片、嵌入绘图或公式对象；这类试卷请转 PDF 或照片。

默认的 `127.0.0.1` 工作台没有登录鉴权，不能直接暴露到公网。多服务器部署需先补租户隔离、权限、独立任务队列、对象存储及数据保留/删除策略。当前后台队列按单个服务进程设计，不要直接开多个 uvicorn workers。

## 模型调用与 Token

- 模型及密钥在网页“模型与策略”设置。切换 API 地址时必须填新密钥，防止把旧密钥发送给新服务商。
- “测试当前连接”发出一次小型付费请求，不上传试卷；它只验证基本连接及 JSON 输出，不证明真实照片识别或评分质量。批量使用前应拿教师已批样本试评。
- 通义、DeepSeek、豆包、智谱及自定义连接走 Responses；Gemini、Kimi、混元、千帆走 Chat Completions；Claude 走 Messages。各平台参数和 Token 统计不完全相同，不能只按模型名称推断费用。
- PDF 对预设视觉模型按需渲染为图片；已有页面图可复用。其他自定义 Responses 服务维持原有 PDF 文件输入行为。
- 原试卷及评分标准在生成或确认时处理一次，固定内容复用，不随每份学生答卷重复上传。客观题可走确定性规则；模型只收到相关单题资料及作答。输出尽量短，并记录模型报告的输入、输出及缓存 Token。
- 已有可靠作答不会在识别重试时反复覆盖。重批沿用已保存作答文本；同题同答案且评分前提未变的稳定结论可命中本地缓存。题目、评分标准、模型、思考模式、评分次数或人工复核变化会使缓存失效。
- 选择性复核模式下，主观题通常至少两次独立评分，一致即停止；三次配置只在需要时继续。相同模型多次同分不等于正确，仍需用教师双评样本评估。

识别置信门槛、抽检比例等是工程初始参数，不是实测准确率。低置信、漏题、模型失败、越界分数、证据不足和模型分歧应留在待处理项。要减少人工工作量，应先统计这些原因，而不是直接放宽阈值。

## 本地开发与接口

```powershell
cd D:\ou\agent
.\.venv\Scripts\python.exe -m pytest
```

运行时 API 清单在 `http://127.0.0.1:8000/docs`，比手写清单更不容易过时。常用端点：

| 端点 | 用途 |
| --- | --- |
| `POST /api/assessments` | 创建试卷 |
| `POST /api/assessments/{id}/documents` | 上传原试卷、答案册、评分标准 |
| `POST /api/assessments/{id}/generate-candidate-key` | 生成候选答案 |
| `POST /api/assessments/{id}/confirm-candidate-key` | 确认候选答案 |
| `POST /api/batches` | 批量上传答卷，默认只保存 |
| `POST /api/assessments/{id}/grade-batch` | 排队批改待批答卷 |
| `POST /api/submissions/{id}/grade` | 单份批改或重批 |
| `POST /api/grade-items/{id}/review` | 人工复核并留痕 |
| `GET /api/knowledge/search` | 检索知识资产 |

知识资料与学生数据在业务库保存；可检索知识库应仅纳入教师批准且已脱敏的材料。意外中断后不要盲目重发全部任务，以免重复计费；先在答卷列表检查已保存、已出分和缺分状态。
