# 答题区坐标校准与编辑修复（2026-10-23）

问题是题号映射正确而坐标偏移。整数网格和越界校验只能保证坐标可裁切，不能证明框住完整作答。本次不重新生成题目、答案或评分标准。

## 处理与使用

- 首次 API 定位后，增加本地 OpenCV 印刷边线校准。已有模板也可点击“本地边线校准”，不发出模型请求。
- 长作答区依据支持四边的印刷框调整；短作答区仅在横线数量与候选区数量一致、行距规则、相邻距离合理时按行列对应。证据不足保留候选坐标，不声称已校准。
- 本地校准跳过人工调整过的题。该校准适用于清晰横线和边框，并非任意照片的通用定位器。
- 区域工作台默认按宽度显示，自动滚到所选作答区；拖动框内移动，四角缩放，框外重新画框，两点框选仍可用。显示比例变化后重绘手柄。
- “本题作答区”逐个选择小问或续答区；“添加续答区／小问区”追加区域。保存、删除仅作用于当前区域，保留其他区域及顺序。跨页时先选择对应页码。
- 点击已有框可打开预览与保存卡片。保存会明确确认当前几何区域，不等同于确认学生答案或评分标签。
- 新增 `PUT /api/assessments/{id}/layout-template/regions/{question_id}`，携带模板版本、来源、区域数组和当前确认索引；旧页面与其他来源的写入返回 409，非法页码或坐标返回 422。只更新位置，不回写整个题目。
- 新增 `POST /api/assessments/{id}/layout-template/calibrate`，离线运算后再次核验模板版本，避免覆盖并发人工修改。
- 界面显示“候选区域待核对”和逐区确认计数，区分模型候选、本地边线校准及人工调整。模型置信度不代表坐标准确率；未人工确认不阻塞既有识别路径。

## 验证

- 完整测试：267 passed，1 skipped（26.18 秒）。使用独立合成资料，API 与 OCR 依测试目的模拟，不产生付费请求。
- 新增验证：印刷横线对齐、续答框扩展、无边框保持原状、原数组不变、人工区域保护、多区域增删、确认状态保留、过期保存拒绝、错误页码／来源／越界原子失败、移动和缩放、按显示比例滚动。
- 实际本地样张：先备份优化数据库；校准 14 道文字题，保留 10 道选择题检测位置。纠正填空及程序阅读横线偏移、分析及编程题外框、跨栏编程续答区截短。本次校准模型调用为零。逐图检查覆盖范围，但没有教师真值，不报告识别或评分准确率。
- 浏览器实际验证：默认宽度显示、滚到当前题、编程题保留两个区域、点击已有框弹出操作卡、裁切预览可用。实际样张未保存为“教师确认”，没有创建学生分数。
- 图片、数据库备份和验证截图仅保存在本地忽略目录 `output/`，不上传仓库。

位置校准不保证手写、代码缩进或流程图结构能被 PP-OCRv5 完整识别；这部分仍需单独评估。修正现有模板后不会自动改写已保存的学生作答或历史分数。
