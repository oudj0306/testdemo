# 优化版维护约定

- 只修改此优化版；生产答卷、配置、密钥和 `output/` 不提交。原版不改动。
- 代码职责与目录见 `docs/代码结构与维护规范.md`。沿现有职责添加模块，避免所有功能重新汇入单一文件。
- 新增或修改的 Python 代码使用明确命名、关键边界类型和说明设计原因的注释。通过 Ruff 检查与格式检查。
- 优先减少重复遍历、重复模型调用和重复符号运算；说明时间与空间的取舍，不以关闭校验换速度。
- 保留缺分与零分的区别；有效 API 数值不因复核提示被清除。保护人工修正、暂停续跑与请求用量计数。
- 外部数据、历史脏数据与模型响应在边界验证。付费模型重试必须有限且有可追踪的错误原因。
- 结构调整后运行全套隔离测试；不自动重启用户生产服务，不为整理代码额外调用付费模型。
- 测试按功能目录归档；移动模块时同步检查 Python 导入、PowerShell 内嵌导入、包资源和维护文档。
- 新增第三方 import 必须声明依赖。CPU/GPU Paddle 不能共装，OpenCV 使用与 PaddleOCR 一致的 contrib 分发包；依赖分组与检查见 `docs/依赖安装与检查.md`。
